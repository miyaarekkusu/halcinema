【チャットボットと共通CSSについて】
>>  チャットボットに関してはcommo.jsから読み取ることができるのでフッターの下にでも書いておいてください

html

  <!-- ===================================================
       全ページ共通JS/CSS の読み込み
       チャットポップアップは common.js が自動挿入します
       =================================================== -->
  <script src="../js/common.js" defer></script>

  <!-- ページ固有JS（不要なら削除） -->
  <!-- <script src="../js/PAGENAME.js" defer></script> -->


 >> そして <head> の CSS 読み込みはこうします。

html  
　<link rel="stylesheet" href="../css/common.css">
  <link rel="stylesheet" href="../css/chatbot.css">
  <!-- ページ固有CSS（不要なら削除） -->
  <!-- <link rel="stylesheet" href="../css/PAGENAME.css"> -->

-----------------------------------------------------------------------------------------------

ポイント整理
・common.css全ページ必須ヘッダー・フッター・ボタンなどchatbot.css全ページ必須ポップアップのスタイルが入っている。

・common.js全ページ必須ポップアップHTMLを自動挿入するchatbot.jschatbot.html のみフルページチャットの動作

・chatbot.css はポップアップのスタイルも含んでいるので、チャットページ以外でもポップアップを表示したい全ページに必要です。
    ※chatbot.js は chatbot.html だけでOKです。

・まとめると「<head> に CSS 2行、</body> 前に JS 1行コピーすれば全ページにポップアップが出る」

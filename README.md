# HAL CINEMA

映画館「HALシネマ 名古屋亀島」予約販売管理Webサイト

---

## システム概要

HALシネマは、架空の映画館「HALシネマ 名古屋亀島」をモデルにした、
座席予約・チケット購入・グッズ販売をWeb上で完結できる予約販売管理サイトです。
HTML / CSS / JavaScript（座席選択画面はThree.jsによる3D描画）で構成されたフロントエンドに
JSON形式の作品データを組み合わせ、上映スケジュールの確認から座席選択、決済、
QRコードチケットの発行、マイページでの管理までの一連の予約体験を再現しています。

## 主な機能

- **上映スケジュール／作品一覧・詳細**：`movies.json` と連携した動的な作品情報表示
- **3D座席選択**：Three.js による3D座席マップ。選択した座席の位置にカメラが移動し、自分の視点でスクリーンの見え方を確
  認できるため、その席が自分に合うか事前に判断できる
- **予約〜決済〜チケット発行**：座席選択 → 決済 → QRコードチケット発行までの一連のフロー（sessionStorageでデータ連携）
- **マイページ**：購入済みチケットの確認、QRコード表示、会員情報の管理
- **グッズ・売店**：カート機能付きのオンライン購入
- **会員登録／ログイン**：新規登録・ログインによる会員機能
- **チャットボット**：予約・上映スケジュールなどの相談やお問い合わせに自動応答（音声読み上げ対応、全ページ共通ポップア
  ップ）。利用履歴に応じたおすすめ映画の提案機能は開発中（2次開発でAPI連携に対応予定）
- **案内ページ**：劇場情報・イベント情報・利用規約／プライバシーポリシー

## 解決している問題

- **窓口・電話予約の手間と混雑の解消**：オンラインでいつでも完結する予約導線を提供
- **「席を選んでも実際の見え方が分からない」という不安の解消**：座席選択時に自分視点でのプレビューができ、購入前に納得
  して席を選べる
- **問い合わせ対応の効率化**：チャットボットが相談・問い合わせに自動応答し、スタッフ対応の負担を軽減（将来的には利用履
  歴に基づくおすすめ提案で、リピート来館の促進も目指す）
- **販売チャネルの拡大**：来店時のみだったグッズ販売をオンライン化

## フォルダ構成

halcinema/
├── css/ → CSSファイル（ページ別・共通スタイル）
├── js/ → JavaScriptファイル（共通処理・ページ別ロジック）
├── html/ → 各ページのHTMLファイル（index.htmlを含む）
├── data/ → movies.json などのデータファイル
├── images/ → 画像ファイル
├── video/ → 動画ファイル（ヒーローセクションなど）
└── note/ → メモ・設計資料

============================================================
  HAL CINEMA 管理者画面（admin/） 現状一覧
  2026-11-10 時点 / ブランチ: feat/admin-management-system
============================================================

※ 全画面とも「画面のみ」。サーバー（API）には未接続で、
   表示されている注文・数値はサンプルデータ。


------------------------------------------------------------
■ 1. ダッシュボード（index.html）
------------------------------------------------------------
  どんな画面：ログイン後に最初に開くトップ画面
  機能      ：・本日の予約数 / フード売上 / グッズ売上 / 入場者数
                のカードを表示（中身は「—」のまま）


------------------------------------------------------------
■ 2. 枠割り当て（schedule.html）
------------------------------------------------------------
  どんな画面：横軸＝時間、縦軸＝スクリーンのタイムライン
  機能      ：・右の映画一覧から枠へドラッグして割り当て
              ・掃除20分込みで枠に収まらない映画は入れられない
              ・上映 / 掃除 / 空き時間 / 予備枠 を色分け表示
              ・枠をクリック → 詳細表示、障害の報告・解除、
                予備枠への振替


------------------------------------------------------------
■ 3. 発券（ticket.html）
------------------------------------------------------------
  どんな画面：発券端末
  機能      ：・見出しのみ（中身は未作成）


------------------------------------------------------------
■ 4. フード（food.html）
------------------------------------------------------------
  どんな画面：スタッフ用端末
              QRを読むと事前注文の受け渡し画面が優先表示される
  機能（タブ）：
              ・受付       … 注文一覧と「受け渡し」ボタン
              ・受理中注文 … 調理中 / 準備完了 の状況
              ・在庫       … 商品ごとの在庫数
              ・POS        … 店頭販売の会計
              ・履歴       … 過去の注文


------------------------------------------------------------
■ 5. グッズ（goods.html）
------------------------------------------------------------
  どんな画面：フードと同じ構成
  機能（タブ）：受付 / 受理中注文 / 在庫 / POS / 履歴


------------------------------------------------------------
■ 6. 入場ゲート（gate.html）
------------------------------------------------------------
  どんな画面：QR読み取りの入場ゲート
  機能（タブ）：
              ・予約状態確認 … 予約番号で検索
              ・通過管理     … 氏名・座席・通過時刻の一覧
              ・座席変更     … 座席マップで選んで変更を確定


------------------------------------------------------------
■ 7. バックヤード（backyard.html）
------------------------------------------------------------
  どんな画面：集計・在庫・シフト管理の予定地
  機能      ：・ダッシュボードと同じカードのみ


------------------------------------------------------------
■ 8. 設定（settings.html）
------------------------------------------------------------
  どんな画面：端末設定の予定地
  機能      ：・「サーバー接続後に実装」の文言のみ


------------------------------------------------------------
■ 全画面共通（admin-common.js）
------------------------------------------------------------
  ・サイドバーで画面移動（スマホ幅では開閉）
  ・ログアウト
  ・QRコード読み取り（全画面表示）


------------------------------------------------------------
■ ログインの仕組み（要改善）
------------------------------------------------------------
  ・html/login.html に管理者ID/パスワードが直書き
  ・ブラウザに「ログイン済み」の目印を置くだけ
  ・サーバー側の認証・管理者用APIはなし
  → 三次開発で管理者認証を作り直す予定


============================================================
  整理後の構成（三次開発の方針 / 2026-11-10 決定）
============================================================

  画面が多く役割も混在しているため、2区分・7画面に整理する。
  （詳細：docs/admin/02_design-distribution-sales-auth.md）

  【管理（事務所）】
    ダッシュボード … 今のダッシュボード＋バックヤードを統合
    作品・配給     … 作品 / 配給会社 / 契約 をタブで切替（新規）
    枠割り当て     … 今のまま
    売上・精算     … 日次締め / 売上集計 / 配給精算 をタブで切替（新規）
    設定           … 管理者アカウント管理

  【現場（端末）】※モック作成者と相談のうえ統合
    窓口           … 入場ゲートのみ（電子チケットのQRで入場）
    物販           … フード＋グッズ

  【廃止】
    バックヤード（ダッシュボードと重複）
    発券（発券機は作らない）

  【ロール別に見えるメニュー】
    支配人（manager）    … 全部
    経理（accounting）   … ダッシュボード / 売上・精算
    スタッフ（staff）    … ダッシュボード / 窓口 / 物販

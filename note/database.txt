================================================================
  HAL Cinema — データベース 確認・操作手順
================================================================

## 前提

  Docker が起動していること（note/docker.txt 参照）
  docker compose up -d --build で API・DB が立ち上がっていること

================================================================
  DBに接続する
================================================================

  以下のコマンドでPostgreSQLの中に入れる：

    docker compose exec db psql -U alex123 -d alex

  成功すると以下のプロンプトが表示される：

    alex=#

  ⚠️ alex-# と表示されたら、セミコロン ; が抜けている。
     ; を入力してEnterを押せば解決する。

  終了するときは：

    \q


================================================================
  よく使うコマンド（psql内で使う）
================================================================

  テーブル一覧を見る：
    \dt

  テーブルの構造（カラム情報）を見る：
    \d t_member
    \d t_movie
    \d t_reservation
    （テーブル名を変えれば何でも見れる）

  データを見る：
    SELECT * FROM t_price_category;
    SELECT * FROM t_member;
    SELECT * FROM t_movie;

  件数を確認する：
    SELECT COUNT(*) FROM t_member;

  終了：
    \q


================================================================
  テーブル一覧
================================================================

  # | 物理名               | 説明
  --+----------------------+----------------------------------
  1 | t_member             | 会員情報
  2 | t_movie              | 映画マスタ
  3 | t_screen             | スクリーン（上映室）マスタ
  4 | t_seat               | 座席マスタ
  5 | t_schedule           | 上映スケジュール
  6 | t_price_category     | 料金区分（一般・学生・シニア）
  7 | t_screen_price       | 上映回ごとの料金
  8 | t_reservation        | 予約ヘッダ
  9 | t_reservation_detail | 予約明細（座席1つ分）
  10| t_ticket             | 発券チケット（QRコード）
  11| t_seat_stock         | 座席在庫（空席・予約済み管理）


================================================================
  接続情報（GUIツール用）
================================================================

  TablePlus・DBeaver・pgAdmin 等で接続する場合：

    Host:     localhost
    Port:     5432
    Database: alex        （.envのDB_NAME）
    User:     alex123     （.envのDB_USER）
    Password: halcinema123（.envのDB_PASSWORD）

  ※ .env の値を変えた場合はここも変わる


================================================================
  DBを作り直したいとき
================================================================

  ⚠️ データが全部消えるので注意！

    docker compose down -v
    docker compose up -d --build

  schema.sql が自動実行されてテーブルが再作成される。
  料金区分（一般・学生・シニア）の初期データも自動で入る。


================================================================
  よくある確認クエリ
================================================================

  ■ 料金区分の確認
    SELECT * FROM t_price_category;

  ■ 上映中の映画一覧
    SELECT * FROM t_movie WHERE f_is_showing = 1;

  ■ 今日の上映スケジュール
    SELECT * FROM t_schedule WHERE f_show_date = CURRENT_DATE;

  ■ 空席数の確認（schedule_id=1 の場合）
    SELECT COUNT(*) FROM t_seat_stock
    WHERE f_schedule_id = 1 AND f_stock_status = 0;

  ■ 会員数の確認
    SELECT COUNT(*) FROM t_member;
